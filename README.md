# iOS Helper Tools

A grab-bag of small, independent tools accumulated while working on iOS
projects.

- [`Git/`](Git) — everyday git workflow scripts (safe branch update with
  stash/rebase, a worked conflict-resolution example).
- [`EncryptorObfuscator.playground/`](EncryptorObfuscator.playground) — a
  Swift playground demonstrating a simple byte-array obfuscation trick for
  hiding literal secrets/URLs from casual source inspection (not real
  encryption — see the playground for the caveat).
- [`Localizables/`](Localizables) — converts an iOS `Localizable.strings`
  file into the JSON shape Firebase Remote Config/Realtime Database expects.
- [`Unit_Testing/Sourcery/`](Unit_Testing/Sourcery) — Sourcery templates
  that auto-generate mock subclasses for models and protocols.
- [`Unit_Testing/UITestHelper/`](Unit_Testing/UITestHelper) — a minimal iOS
  app used as a sandbox for trying out UI-parsing/accessibility tooling
  against simple storyboards/xibs.
- [`UIViewExtension.swift`](UIViewExtension.swift) /
  [`ViewExtension.swift`](ViewExtension.swift) — UIKit/SwiftUI extensions
  for setting accessibility label/hint/value/traits in one call.
